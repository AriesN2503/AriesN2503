## 👨‍💻 About Me

I am **Lê Phạm Trường Huy**, a **Front-End Developer** focused on building clean, performant, and accessible web experiences. I enjoy turning product ideas into polished interfaces with **React**, **Next.js**, **TypeScript**, and **Tailwind CSS**, with strong attention to responsive UI, SEO optimization, and smooth user experience.

My work combines UI/UX thinking with practical engineering: REST API integration, performance optimization, Google Analytics 4 tracking, Linux VPS deployment, and production-minded frontend architecture. I studied **Software Engineering at FPT University** and keep learning new technologies to ship better, faster, and more reliable web applications.
